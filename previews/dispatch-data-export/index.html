订单列表 · 导出数据 PRD

1. 目标与范围

减少页面导出按钮数量，并新增运营派单数据导出。仅调整订单列表导出入口、数据范围和异常反馈；订单数据、风控数据继续沿用现有逻辑。文件字段及格式见左侧“派单数据-Excel”。

2. 导出入口调整

控件点击结果
导出数据替换原“导出”和“导出风控数据”两个按钮；Hover、键盘聚焦或点击后显示三个选项。选择任一类型后立即隐藏下拉菜单，按钮显示旋转 loading 和“导出中”，生成结束后恢复“导出数据”。
订单数据调用系统已有订单导出逻辑。
风控数据调用系统已有风控数据导出逻辑。
派单数据按当前已经生效的运营订单列表筛选条件处理全部结果，不限当前分页。

3. 派单数据导出规则

3.1 先确定订单范围

  1. 以运营当前订单列表为数据范围，读取已经点击“查询”后生效的筛选条件和状态页签。
  2. 处理筛选结果中的全部订单，不限当前分页；不在当前列表筛选结果内的订单不导出。
  3. 在上述订单范围内，再判断订单是否属于以下三类派单订单。命中任意一类即可进入导出范围。

3.2 三类派单订单

派单类型触发及识别规则
系统在途派单规则新订单创建后，系统查询该客户名下状态为“租用中”的有效订单，并按商品品类匹配对应履约商家，支持匹配至三级品类。匹配后校验商家库存、服务范围及账户状态；校验通过则直接派给该商家，不进入公共派单池。导出实际通过该规则产生派单记录的订单。
商品自动派单规则商品已配置派单规则时，用户下单该商品后，系统自动拒绝原商品发布商家的商家单，再按照该商品配置进入派单流程。导出该类订单及系统自动拒单、后续自动派单等完整记录。
转单池运营手动派单订单进入转单池后，由运营选择接单商家并手动发起派单。导出实际产生运营手动派单记录的订单及其完整派单记录。

3.3 导出记录范围

  1. 判断依据为订单历史上的真实派单执行记录，不使用当前规则配置反推历史订单。
  2. 同一订单命中多种派单类型时只纳入一次订单范围，但导出完整派单链路，包括系统自动拒单、拒单、超时、自动转派及运营手动派单。
  3. 数据提取完成后，按左侧“派单数据-Excel”页面规定的字段、排序和格式生成文件。

4. 导出状态与提示文案

场景提示文案处理方式

无符合数据当前筛选条件下暂无可导出的派单数据。不创建空文件；保留筛选条件，运营可调整条件后重试。
导出数量超限导出数据量较大，请缩小筛选范围后重试。由开发评估并提供单次导出可稳定支持的极限数据量，产品确认后将其配置为单次导出上限；超过上限时不提交任务，并建议运营缩短创建时间或增加订单状态等筛选。
重复提交派单数据正在生成，请勿重复操作。复用当前任务，不新建重复任务。
任务创建失败导出任务创建失败，请稍后重试。恢复按钮可点击状态；保留已生效筛选条件并允许重新提交。

部分数据异常派单数据生成失败，请重新导出；如仍失败请联系技术人员。不输出不完整文件；日志记录异常订单号、派单轮次及失败阶段，供技术排查。

5. 失败处理原则

  • 服务端以任务ID保证幂等，避免重复点击生成多份相同文件。
  • 生成失败时保留原筛选条件，不要求运营重新填写。
  • 任何行生成异常时整份文件失败，不静默跳过异常订单。
  • 前端只展示可执行的处理建议；错误详情、异常订单号和堆栈仅写入服务端日志。
  • 订单数据、风控数据沿用各自已有异常处理，本次新增规则仅约束派单数据导出。

1. 文件目标

输出运营可直接筛选和追溯的派单明细。文件只包含“派单明细”一个Sheet，不增加派单分析页。文件名为 yyyyMMddHHmmss_派单数据.xlsx。

2. 行粒度与排序

  • 一条派单记录对应一行，不按订单合并单元格。
  • 同一订单的订单、归属、商品和价格字段在每条派单行中重复填写，便于筛选、透视和逐行分析。
  • 先按下单时间升序，再按订单号、派单时间升序；同一订单的派单轮次从1连续编号。
  • 无数据的字段留空，不输出“——”“无”等占位文本。
  • ID字段按文本格式输出，避免科学计数法或前导位丢失；金额保留两位小数，时间精确到分钟。

4. 重点颜色标记

深蓝色表头：固定字段名称区，冻结首行后横向滚动仍保持可见。

浅蓝灰隔行底色：用于区分相邻派单记录，提高长表阅读性；不代表业务状态。

浅红底＋深红粗体：“派单结果”包含“拒单”时标记，仅高亮该结果单元格，便于运营快速定位失败记录。

浅黄底＋深黄粗体：“最终接单状态”为“接单后转派”时标记，提示该商家曾接单但该次接单已被运营取消并重新派单。

浅绿底＋深绿粗体：“最终接单状态”为“最终接单”时标记，便于定位订单当前最终有效接单记录。

颜色仅辅助阅读，导出值仍为原始文本；不改变筛选与统计口径。红色、黄色与绿色条件格式应覆盖全部数据行，新增行自动继承。

项目要求
Sheet仅“派单明细”一个Sheet。
冻结冻结首行；横向查看时字段表头保持可见。
筛选首行开启自动筛选，39个字段均可筛选。

6. 验收重点

  • 字段顺序严格为A至AM共39列。
  • 同一订单多次派单时，订单信息重复且所有单元格均不合并。
  • 拒单、接单后转派与最终接单的颜色、文字条件和应用范围正确。
  • 同一商家被重新派单时，每次派单独立成行并分别判断最终接单状态。
  • 只输出派单明细Sheet，不输出派单分析Sheet。
